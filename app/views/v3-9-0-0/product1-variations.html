Product 1 variations

There are two versions of the Product 1 page to test with users. This guide explains how to send a participant to each one, what the prototypes can and cannot do, and what each version is designed to test.

The variations

These are links to the hosted prototype. When running the prototype on your own computer, use the same path after your local address, for example http://localhost:3000/v3-9-0-0/p1/existing-map-features.

How to link participants to a variation

  1. Give the participant the link for the variation you want to test, from the table above.
  2. The link remembers the variation, then opens the map with the site boundary from the Product 1 mock-up already drawn.
  3. The participant selects Get summary report to go to the results page.
  4. When the participant selects View downloadable flood map for this location, they are taken to the variation you chose.

The variation is not shown in the address of the map or results page, so participants cannot see which version they have been given.

! Warning The variation is remembered in the browser until it is changed or the prototype data is cleared. Always use a variation link at the start of each session, even if the same browser was used for a previous participant. If no variation has been chosen, participants see the existing map features option.

The links on the prototype home page use the same links, so designers and researchers can check each journey before a session.

What each variation tests

Existing map features

The maps use the same map features and styling as the flood map for planning today, with see-through flood colours. It is the simplest option to build, as it needs no new map features. The solid colours variation tests features that could make the maps more accessible.

Both variations share the same responsive HTML page, which users can preview before they print or download it. It includes all the data available on the flood map for planning for the site: flood zones, flood zones with climate change, surface water and surface water with climate change.

  • Users can choose what to include, add a reference and set the scale on the page, then apply their settings
  • Flood zones come first, as research found they are the priority data
  • An "at a glance" table gives a quick answer for each dataset
  • Surface water shows a 1 in 100 chance by default, with 1 in 30 and 1 in 1000 as an option

Solid colours with map details on top

Flood data on the black and white maps is shown in solid colours that exactly match the key, instead of see-through colours. Road names, road lines and property lines are drawn above the flood data, in white where they cross it.

Accessibility advantages:

  • Colours on the map match the key exactly, so they are easier to match for users with low colour vision
  • Stronger contrast between flood data and the base map
  • Street names and property lines stay readable inside flooded areas, which helps users locate their site
This has been discussed but is not yet planned. It would need to be investigated as a new feature, as it changes how the map layers are drawn.

Limitations of the prototypes

  • Both variations use fixed map images captured from the flood map for planning. The maps do not change with the participant's boundary or location
  • Both variations use the location from the example Product 1 (443574/161376)
  • The surface water results in the "at a glance" table are illustrative
  • Choosing a scale only changes the label shown beside the flood zone maps, not the maps themselves
  • Download PDF downloads a fixed example PDF with the default settings. It does not include the participant's reference or data choices. Print this page does follow their settings
  • In the solid colours variation, map labels on the edge of a flood area can be partly white and partly dark, because they were redrawn from map images
